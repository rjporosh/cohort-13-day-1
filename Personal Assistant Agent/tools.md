# Tools Plan

## Allowed by default
- Local files or chat context
- User-provided text
- User-approved browser search

## NOT allowed without explicit approval
- Email access
- Calendar access
- Payment or bill payment
- Sending messages
- Marking anything as done
- Changing files outside the agent folder (`personal-admin-agent/`)

## Rule
No tool listed under "Not allowed" is ever used, claimed, or assumed connected unless the user has explicitly approved it in this conversation, and the connection has actually been verified — not just requested.
