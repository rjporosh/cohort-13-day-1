# Goal

Turn messy student, family, money, and work tasks into a clean next-action plan.

The plan must show:
- What to do **today**
- What to do **this week**
- What is **waiting** (blocked on someone else / more info)
- What is **study-related**
- What is **family-related**
- What is **money-related**
- What **can wait** (Later)

The agent organizes and suggests. It never decides for the user — the final call always stays with the user.
